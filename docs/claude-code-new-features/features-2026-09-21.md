# Claude Code — What's New (2026-09-21)

## New Features

- **AGENTS.md support**: Claude Code now reads `AGENTS.md` as the project instructions file when no `CLAUDE.md` exists; configurable under "Project instructions" in `/config` (not yet on Bedrock, Vertex, or Foundry).
- **Server-side auto mode classifier**: Auto mode for Claude API and Enterprise users (and on Bedrock, Vertex, Foundry, and gateways) now defaults to the server-side classifier, which does not charge for classifier overhead; `CLAUDE_CODE_AUTO_MODE_SERVER=0` opts out, and `/status` shows a new "Auto mode server" row.
- **Send-now key**: A new `ctrl+enter` (or `ctrl+x ctrl+s`) shortcut interrupts the current turn and sends all queued messages at once; queued messages display in gray until the model receives them.
- **Fast mode in Remote sessions**: Fast mode now works in Claude Code cloud and self-hosted runner sessions; the host's fast-mode setting or typing `/fast` applies where your organization allows it.
- **Skills and plugins sync**: Skills and plugins enabled on your claude.ai account now sync automatically to terminal sessions signed in with it; opt out with `syncClaudeAiSkills: false` or `syncClaudeAiPlugins: false`.
- **Critical memory warning**: A visible warning now appears when memory usage is critical, with steps to free memory or restart safely.
- **Gateway account confirmation**: The signed-in account is now shown during Claude apps gateway sign-in so you can confirm it before the credential is saved; `/status` also shows it.

## Improvements

- Session startup for SDK and headless (`-p`) runs no longer waits on the per-directory `CLAUDE.md` lookup, reducing latency.
- Subagent results now arrive under a header marking them as subagent output so text in a subagent's result cannot be mistaken for the session's own instructions.
- `claude plugin install` now reports when the marketplace offers a newer version of an already-installed plugin.
- `--system-prompt` with a `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__` line now caches the text above it globally, matching the SDK array form.
- The deprecated `TaskOutput` tool has been removed; use the `Read` tool to access a background task's output file instead.

## Bug Fixes

- Fixed a regression where every request failed with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` points at a proxy or gateway.
- Fixed unexpected logouts when an older Claude Code build (such as an IDE extension's bundled CLI) ran alongside the current version.
- Fixed `claude -p` and Agent SDK sessions that could hang with no result after an internal error; they now report the error and exit with code 1.
- Fixed conversations failing every request with "text content blocks must be non-empty" when an earlier assistant turn held an empty text block.
- Fixed background sessions (`claude --bg`) exiting when a plugin's LSP server closed its stdin.
- Fixed multiple crashes on launch when `~/.claude.json` holds malformed values for `theme`, `mcpNeedsAuthNoticed`, or `customApiKeyResponses`.
- Fixed sandboxed Bash on Linux reporting exit code 0 for failed commands when the shell is zsh.
