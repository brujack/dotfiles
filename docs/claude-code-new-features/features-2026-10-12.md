# Claude Code — What's New (2026-10-12)

## New Features

- **`code` policy key in Claude apps gateway** — the same managed settings as `cli`, also applied in Claude Desktop's Code tab; enables gateway mode there alongside `desktop`
- **`autoCompactWindow` in subagent frontmatter** — lets a subagent auto-compact its context window earlier than the main conversation's window
- **`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` env var** — runs every workflow agent on one model while other subagents keep their own
- **`CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`** — sets the maximum backoff delay when retrying overloaded (529) requests
- **`allow_large` option on the Read tool** — reads a text file past the usual size limit in one call when the whole file is needed
- **`onFailure: "block"` for command and HTTP hooks** — a hook that can't start, times out, or exits unexpectedly now blocks the action instead of letting it through
- **Program Status Protocol (OSC 7501)** — terminals that implement it can show whether Claude Code is working, waiting, or done
- **`$.ui.notify` for mods** — raises a native notification through your own notification channel
- **`models` list on Claude apps gateway upstreams** — only listed models are routed to a given upstream, including on failover
- **`forceLoginMethod: "gateway"` in user settings** — directs `/login` to a specific Claude apps gateway on machines with no managed settings
- **[Claude Tag] Workspace/channel memory management** — members with Claude Tag Admin can now create, edit, and delete memory files from the Activity page

## Improvements

- Sonnet 5.5 cache read pricing updated to $0.10/M tokens (was $0.20) in `/cost`, status line, and SDK
- MCP tool description character limit raised from 2,048 to 4,096 for descriptions loaded up front; tool-search-loaded descriptions raised to 16,384
- `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC` no longer rewrites a large transcript when doing so would free under 10% of it
- Background requests behind a Claude apps gateway now use Haiku 4.5 instead of the session's model
- Grep now accepts `-l`, `-c`, and `-r` flags instead of failing the call
- `[VSCode]` Claude in Chrome now asks before browser actions in every new session; allowing a site stops repeat asks

## Bug Fixes

- Fixed managed-settings `PreToolUse`/`prompt` hooks that deny a call not properly refusing it in some cases
- Fixed headless sessions starting disabled `.mcp.json` or plugin MCP servers after a `cd` or plugin reload
- Fixed token counts for Haiku 5.5 and adaptive-thinking-only models behind some gateways
- Fixed Edit replacing non-ASCII characters in non-UTF-8 files (Windows-1252, Shift-JIS, GBK); such edits are now refused
- Fixed workflow scripts silently truncating deeply nested results
- Fixed a plugin secret named `constructor` or `prototype` being deleted on the next options save
- Fixed PowerShell commands over ~1 KB always prompting for permission; allow rules now apply up to 32 KB
- Fixed `[Windows]` stdio MCP servers being force-killed at shutdown instead of receiving a clean stdin-close first
- Fixed the terminal freezing for seconds or minutes on syntax-highlighted code with very long lines or unclosed strings
- Fixed replies whose quotes nest deeper every few lines causing gigabytes of memory use
- Fixed bold text drawn faint after dim text in piped output
- Fixed `[VSCode]` `claudeCode.spinnerVerbs` missing from extension settings, causing broken chat panels
- Fixed Code Review check sometimes staying "in progress" after a review finished
- Fixed cloud sessions waiting for a self-hosted runner all showing the same queue position
