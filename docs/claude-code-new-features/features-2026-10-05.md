# Claude Code — What's New (2026-10-05)

## New Features

- **Claude Sonnet 5.5** (`claude-sonnet-5-5`) is now the default Sonnet model — 1M context, $2/$10 per Mtok with $0.20/Mtok cache reads.
- **Claude Mods** introduced: plugins may now modify deeper Claude Code behavior, enabling a new class of first-party and user-installed modifications.
- **"You Should Know"** is a built-in mod where a side agent watches your session and flags things you or Claude might miss; enable with `/plugin enable cc-plugin-you-should-know@builtin`.
- **`$.ui.selection()`** added for mods, returning text selected in fullscreen mode and the matching transcript row.
- **`claude --desktop`** opens the Claude desktop app on the current directory, or a specific session with `--continue` / `--resume`.
- **`/mcp reconnect all`** retries every failed or unauthenticated MCP server at once.
- **`allowedProviders`** managed setting limits which API providers (Anthropic, Bedrock, Vertex, etc.) a machine may use.
- **`CLAUDE_CODE_DISABLE_WEB_FETCH`** environment variable disables the WebFetch tool.
- **`--max-findings <n>|all`** added to `/code-review` to control how many findings are reported; the choice persists until reset.
- **`agent.spawn`** added for teammates with a unified agent id across plugin hook events, plus idle and waiting states in `$.agent.list()`.

## Improvements

- **Ctrl+C prompt recovery**: pressing Up after clearing with Ctrl+C restores the draft, including pasted text and images.
- **Spend meter** now shows dollar amounts (e.g. "$271 / $500 spent this month") in `/usage` and the status line for Claude apps gateway users.
- Permission prompts now show a count like "2 of 5" when several requests stack up.
- Mid-response API timeouts no longer fail the turn — sessions continue from the partial response.

## Bug Fixes

- Fixed `Read` deny rules not applying to files accessed through symlinks.
- Fixed dangerous `rm` commands (e.g. on `/` or `~`) losing their always-ask safeguard when output was also redirected.
- Fixed Bash sandbox auto-allow missing commands with environment variable prefixes before the command.
- Fixed resumed sessions sometimes dropping files, context, or earlier thinking blocks from compacted history.
- Fixed MCP credential values leaking into error messages when "Bearer" or "Basic" preceded the key name.
- Fixed "Prompt is too long" errors persisting after compaction by compacting again when needed.
