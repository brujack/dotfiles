# Claude Code — What's New (2026-08-17)

## New Features

- **Subagent forking on by default** — `subagent_type: "fork"` inherits the full conversation and prompt cache; non-teammate agents in interactive sessions now run in the background by default.
- **`@`-mention sessions** — type `@` to address another live Claude session by name; `SendMessage` delivers to a bare name matching exactly one live session.
- **GitLab support** — bare `gitlab.com` URLs work in plugin marketplaces; `--worktree` and `claude agents` show GitLab MR URLs; GitLab token families get full secret redaction.
- **Plugin marketplace `command` sources** — a local command (e.g. an IDE) prints a plugin directory, re-resolved each session with no restart required.
- **SSE keepalive pings** — gateway streaming sends pings during long thinking pauses, preventing idle-timeout disconnects on Vertex and Bedrock.
- **Self-hosted runner hook support** — server-supplied Claude Code hooks now fire in self-hosted runner sessions.
- **Memory cgroup support on Linux** — opt-in `CLAUDE_CODE_TOOL_MEMORY_LIMIT` prevents a runaway build from stalling the session.
- **Todo tools gated by default** — `TaskCreate`/`TodoWrite` etc. are disabled on Opus 4.8, Sonnet 5, Fable 5, and newer; set `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` to restore.

## Improvements

- `/code-review` at high/xhigh/max effort now runs in a background agent.
- `ListAgents` labels disconnected Remote Control sessions as `offline` and cloud sessions as `cloud`.
- Remote Control reconnects for ~30 minutes after a network blip; terminal describes what ended the session.
- Workflow fan-outs stagger same-prefix sibling agents to hit the prompt cache.
- [VSCode] Session groups added to the sidebar — right-click to create, rename, or delete.
- [VSCode] `/btw` side-question panel is now resizable.
- `/plugin install` refreshes the marketplace first, so newly published plugins install without a manual update.
- Slash-command menu: only the selected row is highlighted in blue; matched characters are bolded.

## Bug Fixes

- Fixed a PowerShell permission bypass where variable-writing parameters could overwrite `$PSDefaultParameterValues`.
- Fixed a Windows permission bypass where Git Bash followed Cygwin-style symlinks past path validation.
- Fixed nested git repositories inheriting trust from a parent directory.
- Fixed MCP connections hanging 30 s when a server sent a malformed protocol-version reply.
- Fixed idle Linux sessions pinning a CPU core at 100% when sandboxing was enabled.
- Fixed Windows NT `\??\` device-prefix paths bypassing UNC path validation (NTLM credential-leak vector).
- Fixed MCP OAuth sign-in failing with redirect URI mismatch for pre-registered OAuth clients (e.g. Slack).
- Fixed session cleanup deleting contents inside a project's memory folder.
- Fixed Remote Control sessions appearing as a new claude.ai session on every resume from Desktop or an IDE.
- Fixed long streaming responses partly disappearing and printing twice in the terminal.
- Fixed `/tui` reverting the session to an older model after `/model` was changed.
