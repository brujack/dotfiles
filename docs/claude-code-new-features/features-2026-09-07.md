# Claude Code — What's New (2026-09-07)

## New Features

- Added Claude Fable 5.1 (`claude-fable-5-1`) as the new default Fable model, with 1M context and $10/$50 per Mtok pricing
- Added `/skill-doctor` to show which loaded skills go unused and what they cost in context
- Added a fullscreen diff panel (`/diff`) showing uncommitted changes beside the conversation
- Added `managedMcpServers` managed setting so organizations can provide HTTP/SSE MCP servers to all users
- Added `--permission-prompts none` for unattended headless hosts to deny prompts automatically
- Added "Time format" (`timeFormat`) and `timeZone` settings for turn-end clock and transcript timestamps
- Added `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` to apply a model to every subagent regardless of per-spawn overrides
- Added `bashOutputMaxChars` and `taskOutputMaxChars` settings to raise inline output limits up to 128K characters
- Added `--append-subagent-system-prompt-file` to supply large subagent system prompts from a file
- Added recognition of `glab mr` commands so GitLab merge requests show as `MR !N` in the tool summary
- Added an "Organization policy" line to `/status` and `claude doctor` explaining policy-load failures
- Added a Containment Escape auto-mode rule blocking cloud metadata fetches and egress evasion by default
- Added `s` flag in `/effort` to change effort for the current session only, matching `/model`
- Added `--json` to `claude plugin validate` for machine-readable validation output
- Added a one-time auto-mode prompt before the first file read outside working directories
- [VSCode] Added a diff panel showing uncommitted changes; `/skill-doctor` for context auditing; "Archive session" to session list; Add/Remove server form in MCP dialog; fold button on permission prompts

## Improvements

- Improved `/model` picker to show friendly model names instead of raw Bedrock/Vertex IDs
- Improved auto-compact for 1M-context models: Opus and Fable sessions now compact just before the limit
- Improved `/ultrareview` to wait up to 45 minutes (was 30) for long cloud reviews
- Improved streaming performance by skipping redundant layout passes on already-rendered blocks
- Improved the dangerous-`rm` safety prompt to catch more shell expansion patterns

## Bug Fixes

- Fixed Claude Code failing to launch on macOS 12 Monterey
- Fixed `Edit`/`Write`/`Read` permission rules with parentheses being silently dropped
- Fixed Bash `Read()` deny rules missing files passed as option values or in compound commands
- Fixed the prompt cache being invalidated on every OAuth token refresh in telemetry-disabled sessions
- Fixed fullscreen mode showing a blank conversation after turns with hundreds of tool calls
- Fixed concurrent sessions silently reverting each other's `~/.claude.json` changes
- Fixed managed settings going unenforced when a settings file could not be parsed; Claude Code now refuses to start and names the source
- Fixed subagents dying on a first-call model 404; they now fall back to the session's fallback model chain
