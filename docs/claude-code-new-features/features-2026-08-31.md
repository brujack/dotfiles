# Claude Code — What's New (2026-08-31)

## New Features

- Added `PreModelSwitch` and `PostModelSwitch` hook events so hooks can block, confirm, or annotate a model switch; `SessionStart` resume hooks now receive session staleness and estimated re-cache cost
- Added live streaming of a foreground subagent's tool calls and results to Remote Control clients
- Added a Spend limit bar to `/usage` and a `rate_limits.spend_limit` status line field for sessions behind a Claude apps gateway with spend limits
- Added per-session prompt-cache stats to `/cost`: hit ratio, misses, tokens re-cached, and warm/cold state
- Added `--restricted` flag (or `CLAUDE_CODE_RESTRICTED=1`) to remove command/code tools, restrict file access to the working directory, and ignore user/project settings
- Added `experimental.cacheTtl` to agent frontmatter for a per-agent prompt cache TTL override
- Added cross-session messaging (`SendMessage` / `ListAgents`) on Bedrock, Vertex, Foundry, and telemetry-disabled sessions
- Added the `SendFeedback` tool so Claude can draft feedback reports for review and submission via `/feedback`
- Added an Auto mode tab to `/permissions` for viewing and editing auto mode classifier rules
- Added a Loops breakdown to `/usage` showing per-loop run count, total tokens, and tokens per run
- Added `modelPicker` setting to curate the `/model` picker with a custom ordered, labeled model list
- Added `promptCacheTtl` and `subagentPromptCacheTtl` settings for API-key users to keep a 1-hour cache on the main conversation while subagents use 5 minutes
- Added keyless sign-in via Anthropic Console account under `/login`, removing the requirement to create an API key
- Added `/claude-api cost-optimize` to profile and optimize Claude API spend through caching, token hygiene, batching, effort, and model selection
- Added turn completion time to the end-of-turn duration line and the model/effort level per subagent to `/tasks`

## Improvements

- Reduced the Workflow tool's prompt footprint from ~5.7k tokens to ~1k; the script-writing reference moved to a bundled `workflow-authoring` skill
- Native binary is ~5 MB smaller and zstd-compressed for downloads (~75 MB vs 340 MB on Linux x64)
- Startup time improved: sandbox and MCP bring-up no longer block the first frame
- Reduced memory usage in native builds (~40–70 MB less per session) and improved GC in long-running sessions
- PR badge now checks GitHub less often while the pull request is unchanged

## Bug Fixes

- Fixed a security issue where file tools (Read, Write, Edit) could follow a symlink swapped after the permission check, potentially reading or writing outside the approved location
- Fixed plugin commands being able to point outside the plugin directory via path traversal
- Fixed a startup crash on Linux distributions shipping glibc 2.44 (Arch Linux, CachyOS, Fedora Rawhide)
- Fixed Bash sandbox cleanup deleting a dotfile-managed `~/.claude/settings.json` symlink (nix/home-manager, stow)
- Fixed background sessions failing to open after 45 seconds when the starting directory was deleted or the machine had slept
- Fixed sessions going silent for 10+ minutes when the API returned no response; requests now time out after ~3 minutes and retry once
- Fixed conversations stuck on "text content blocks must be non-empty" errors after turns where the model produced only thinking output
- Fixed background subagents being unable to edit files inside a git worktree they created
