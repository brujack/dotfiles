# Claude Code — What's New (2026-08-10)

## New Features

- **Self-hosted runner**: `claude self-hosted-runner` turns your own machines or containers into a place Claude Code web, mobile, and desktop sessions can run (Team and Enterprise plans).
- **Cross-session messaging**: Claude Code sessions can now message each other on any of your machines using `SendMessage` and `ListAgents` to discover them; `SendMessage` can also initiate conversations with Remote Control sessions by name.
- **Archive plugin source**: Install plugins from a zip over HTTPS without git or npm, with optional SHA-256 integrity pinning.
- **VSCode Focus view**: Hides tool activity behind an expandable per-turn summary with a live running-tool indicator; toggle with `Ctrl+Alt+F` or "Claude Code: Toggle Focus view."
- **Sandbox credential masking** (`mode: "mask"`): Sandboxed commands on Linux/WSL see a sentinel credential copy while the proxy substitutes the real value on egress.
- **Gateway spend-limit in usage warnings**: The limit-reached message now names the cap, its reset time, and the operator's message.
- **`prompt-audit` subcommand** added to the `claude-api` skill for auditing prompts and tool descriptions for patterns written for older models.
- **Owner wildcards** (`"owner/*"`) in `strictKnownMarketplaces` and `blockedMarketplaces` managed settings allow or block all repos under a GitHub org at once.

## Improvements

- Background sessions now commit and push to preserve work, and open draft PRs only when the task calls for one.
- `/plugin install` refreshes a stale marketplace catalog before reporting a plugin not found; newly installed plugins activate immediately when safe.
- Sessions forked with `/fork` now get their own git worktree instead of sharing the original session's checkout.
- `/review` is now an alias for `/code-review`; running `/code-review` with no effort level reuses the last level you typed.
- Remote Control: photos attached from the Claude app are shown directly to Claude instead of triggering a separate disk read.
- The 200-subagent-per-session spawn cap has been removed; long-running sessions no longer refuse new agents (concurrency and depth limits still apply).
- `CLAUDE_CODE_DISABLE_1M_CONTEXT` now applies to every Claude model with a native 1M context window, not just a fixed list.

## Bug Fixes

- Fixed Bash permission-check bypasses where crafted commands or zsh `[[ ]]` regex conditionals could hide commands from the analyzer.
- Fixed sandbox filesystem deny entries with trailing slashes being silently bypassable on Linux and macOS.
- Fixed worktree-isolated sessions and subagents running destructive git commands against the main checkout.
- Fixed the startup connectivity check hanging behind an HTTPS proxy.
- Fixed `SendMessage` reporting success when the write to a recipient's inbox had actually failed.
- Fixed long project paths resolving to another project's session directory under a shared sanitized prefix.
- Fixed a permission gap where `bypassPermissions` mode in agent definitions ignored the org's disable policy.
