# Claude Code — What's New (2026-07-27)

## New Features
- **Claude Opus 5** is now the default Opus model, offering 1M context window and fast mode at $10/$50 per Mtok
- **Emoji shortcode autocomplete** in the prompt input — type `:smile:`-style codes or partial strings for suggestions (disable with `emojiCompletionEnabled` setting)
- **`/code-review` runs as a background subagent**, keeping your conversation clean and enabling stacked slash commands as the review target
- **Nested subagents** can spawn sub-subagents up to depth 3 by default (was 1); configurable via `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`
- **`sandbox.network.strictAllowlist`** setting denies non-allowlisted hosts for sandboxed commands without prompting
- **`sandbox.filesystem.disabled`** setting skips filesystem isolation while keeping network egress control active
- **`DirectoryAdded` hook** fires after `/add-dir` or the SDK `register_repo_root` request registers a new working directory mid-session
- **`workflowSizeGuideline`** settings key lets you configure the dynamic workflow size advisory from any settings file
- **Subagent concurrency cap** added (default 20 concurrent subagents; override with `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`)
- Warnings now shown when transcript writes are failing (e.g. disk full) or when session saving is disabled by an inherited environment variable

## Improvements
- `/ultrareview` now accepts plain-language arguments like "review my auth changes" — runs a branch review with the text applied as a note to findings
- Auto mode no longer opens permission dialogs for dangerous-rm, background-`&`, and suspicious-Windows-path checks — the classifier adjudicates them instead
- `claude mcp list` and `/mcp` now show HTTP status and error text when a server fails to connect, plus warnings for config values with hidden whitespace
- Dynamic workflows default to a medium size guideline (fewer than 15 agents); configurable via `/config` or the `workflowSizeGuideline` setting
- `/deep-research` now only launches when manually invoked — Claude no longer starts it unprompted
- Footer PR badge links are now clickable hyperlinks even when terminal hyperlink support cannot be auto-detected (opt out with `FORCE_HYPERLINK=0`)
- Screen reader mode announces deleted text for word and line deletions
- Skills with `context: fork` now run in the background by default; opt out per skill with `background: false`

## Bug Fixes
- Fixed quadratic performance slowdown in long sessions where message normalization cost grew with the number of turns
- Fixed Windows paths with `\u`-prefixed segments (like `C:\Users\unicorn`) being corrupted into CJK characters in tool inputs
- Fixed the left arrow key discarding the current conversation without a confirmation prompt after editing
- Fixed auto-compact never triggering for Claude Opus 4.8 on Bedrock and `/compact` failing once over the context limit
- Fixed corporate mTLS, TLS-verify, OAuth scope, and proxy settings being ignored in Claude Desktop sessions
- Fixed `--max-budget-usd` not stopping background subagents once the spend cap is reached
- Fixed `/ultrareview` failing when given descriptive arguments instead of a branch name
- Fixed multi-line paste collapsing into one line with `j` in place of newlines on certain terminals
- Fixed Windows auto-update failures that could leave `claude.exe` missing after a failed update
- Fixed a memory leak where truncated MCP tool outputs kept the full untruncated result in memory for the entire session
