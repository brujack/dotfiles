# Claude Code — What's New (2026-11-09)

## New Features

- **MCP tasks in terminal**: MCP server tool calls that run as tasks move to the background immediately; set `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1` to wait inline instead.
- **`permissions.denyInsteadOfPrompting`**: Tool calls requiring a permission prompt are denied and the turn continues instead of pausing for input, useful for automated sessions.
- **`/claude-api latency-optimize`**: New slash command that finds where your Claude API code adds latency and tests faster settings against your eval.
- **`CLAUDE_CODE_DISABLE_FEATURE_FLAGS`**: New env var that stops feature-flag fetching without disabling telemetry; every flag uses its built-in default.
- **`/tasks` "Earlier in this session"**: Finished subagents are now listed under a new row so you can reopen and message them even after they leave the main list.
- **Agent SDK `onFailure: "block"`**: Hook callbacks can now block an action on failure instead of allowing it to run.
- **Gateway cost report API**: New `GET /v1/organizations/analytics/cost` endpoint for reading past spend over a date range, by developer, day, or IdP group.
- **Gateway pooled budget controls**: New `admin.pooled_conflict_rule` and `admin.pooled_priority_order` settings to control which group budget pays first for developers in multiple groups.
- **Email-to-network check**: Claude Code now asks before a web or shell tool call sends your account email address to the network.

## Improvements

- **`/model` picker**: Older models are now grouped under a "More models" row instead of being listed inline.
- **`/context` table**: Each list keeps only its 10 largest rows, and MCP tools that load on demand share one row per server until called, keeping the table Claude reads compact.
- **Windows config saves**: Claude Code waits longer for files locked by another program, reducing the chance of an empty `~/.claude.json` after a kill.
- **Chrome extension reconnect**: After a brief disconnect, the extension waits up to 6 seconds for the session's own browser before picking another.
- **`javascript_tool` results**: Results up to 60,000 characters now stay in the conversation instead of being saved to a file.

## Bug Fixes

- Fixed a **Bash permission bypass** where a crafted environment prefix could hide part of a command from permission checks.
- Fixed a **sandbox escape** when creating a worktree.
- Fixed MCP servers on the older handshake failing to connect or returning empty results.
- Fixed `/diff` failing or showing blank when a git repo has a file or folder named `HEAD`.
- Fixed slash commands typed after a leading space or tab being sent as plain text instead of running.
- Fixed a 401 auth error cascading to refresh your login on every retry and invalidating other sessions.
- Fixed `~/.claude.json` and settings files ending up empty when the disk fills during a save.
- Fixed `/clear` killing running commands of background agents and teammates that should keep running.
- Fixed cloud sessions losing session-scoped permission rules when moving to a new worker.
