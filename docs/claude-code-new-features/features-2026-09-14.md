# Claude Code — What's New (2026-09-14)

## New Features

- **`claude plugin eval`**: Run a plugin's eval suite and get scored, reproducible results with JSON and HTML report output.
- **`/output-style [name]`**: List and switch output styles in any session, including Remote Control and cloud/headless sessions.
- **Bash edit diff**: The Bash tool now shows a diff of files changed by a command when `bashEditDiffEnabled` is set.
- **`CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`**: Raise the Workflow tool's concurrent agent limit (1–256) for inference-bound fan-outs.
- **`maxEffortLevel` setting**: Cap effort level globally or per model, including Bedrock, Vertex, and Foundry.
- **`--system-prompt-snapshot off`**: Render the system prompt fresh on every request instead of reusing the recorded one.
- **`--plugin-dir` folder support**: Point at a folder of plugins; child folders load automatically and live additions/removals are picked up.
- **VSCode agent map**: An "N agents" footer pill opens a map of sub-agents with per-agent cards, Stop controls, and read-only transcripts.
- **VSCode Hooks and Permission dialogs**: New command menu dialogs to view, add, edit, or remove hooks and permission rules.
- **Web: Retract queued messages**: Remove a queued message before Claude reads it; text returns to the message box.

## Improvements

- Prompt cache stability significantly improved: multiple fixes prevent misses when resuming sessions, switching models, reconnecting MCP servers, or using subagents.
- Auto mode denials now name the blocking rule and suggest a safer alternative.
- `/diff` panel opens fully rendered without a loading flash.
- Claude Tag scheduled routines can reply in an existing thread instead of always posting a new top-level message.
- Slash commands mid-prompt now show matches as a list instead of a single suggestion.

## Bug Fixes

- Fixed read-only git commands triggering permission prompts (regression from prior release).
- Fixed HTTP 400 errors on third-party Anthropic-compatible endpoints introduced in a prior release.
- Fixed WebFetch hanging indefinitely on servers that never close their response.
- Fixed keyboard input issues in kitty, WezTerm, and rxvt-unicode terminals.
- Fixed `!` negation permission rules applying beyond their source settings file.
- Fixed MCP server configs revealing secrets (tokens, passwords) in error messages.
- Fixed session compaction mangling text containing `$` sequences.
- Fixed symlinked directory deny/ask rules not applying at real path spellings.
