# Claude Code — What's New (2026-08-24)

## New Features
- **GitLab MR badge** added to the footer and statusline; GitLab merge request URLs now supported in `--worktree` and `claude agents` view
- **Concise output style** built in: Claude leads with results and skips preamble — select via `/config` or style picker
- **Spellcheck** (`spellcheck` setting) underlines misspelled words in the prompt input
- **`ANTHROPIC_DEFAULT_MODEL` env var** sets the model new sessions start on without editing settings
- **`keybindingFlavor` setting** enables readline-style word deletion (Ctrl+W, Alt+Backspace, Ctrl+U, Ctrl+K)
- **`CLAUDE_CODE_PROJECT_DIR_NAME` env var** customizes the project directory name used in session isolation
- **`selection:clear` keybinding action** clears text selections in the prompt input
- **`/claude-api upgrade`** command migrates Python projects from `anthropic` 0.x to 1.x
- **Alpine/musl builds** now support native image paste, clipboard, and audio-capture add-ons
- **Windows cross-session messaging** is now available via `SendMessage`/`ListAgents`
- **`notify_when_idle` for `SendMessage`** holds delivery until the recipient session is idle before delivering
- **Usage limit auto-continue**: Claude Code sessions resume automatically when a claude.ai usage limit resets
- **Proxy authorization options** added for egress proxies requiring fresh auth headers per request
- **`claude self-hosted-runner --defer-shutdown-max-min`** controls the graceful shutdown window

## Improvements
- Cost estimates (`/cost`, status line, `--max-budget-usd`) now include the 1.1× US-only-inference premium for data-residency workspaces
- Usage-limit messages now show when the session or weekly limit resets
- Cloud session plugins now display as `name@synced` for clarity
- `ListAgents` now tells a session its own name and lists live teammates (previously only subagents appeared)
- `/usage` now shows the usage-credits spend row for Team and Enterprise members
- Session titles are now short, specific names rather than full sentences
- `SendMessage` now refuses oversized messages up front rather than failing mid-delivery
- Remote Control marks a session offline within seconds when the CLI exits
- Long file paths on tool-use rows now truncate in the middle
- Plugin marketplace `headersHelper` runs a command to supply auth headers dynamically
- `keybindingFlavor: "readline"` now covers Bash word-key bindings in addition to zsh

## Bug Fixes
- Fixed Bedrock streaming behind proxies that strip the response Content-Type header
- Fixed Claude Code hanging at startup with Bedrock SSO behind an HTTPS proxy
- Fixed prompt caching for sessions using an LLM gateway or custom base URL
- Fixed markdown rendering becoming extremely slow for some messages
- Fixed consecutive shell commands splitting into multiple "Ran 1 shell command" rows
- Fixed vim mode: Escape now switches to NORMAL mode without clearing text
- Fixed memory growth in long interactive sessions
- Fixed hooks failing with "posix_spawn ENOENT" after the session working directory was deleted
- Fixed remote sessions exiting when a client delivered a message without a valid role
- Fixed `.worktreeinclude` patterns starting with `**/` silently matching nothing
