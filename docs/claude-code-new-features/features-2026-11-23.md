# Claude Code — What's New (2026-11-23)

_The previous state snapshot was empty, so the whole changelog counted as new. This digest covers the latest release only._

## New Features
- Sign in to organizations managed in the Enterprise Admin Console; Claude Code applies the organization's settings and cloud provider or gateway.
- Added easel, a built-in mod that draws charts on request and for MCP metrics results; automatic charts can be turned off in `/config`.
- Added `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` to print the full sign-in link.
- Self-hosted runner: added `--start-dir` to start work in a folder of a repository.
- Added `commandPrinted` and `commandFailed` fields to `claude plugin install --json` results.
- Added two new self-hosted runner `/metrics` timing gauges.
- VS Code: added `/fork`, `/workflows`, and the `claudeCode.escapeStopsClaude`, `claudeCode.pinPrompt` and `claudeCode.contextUsageThreshold` settings.

## Improvements
- The claude.ai sign-in link is now much shorter.
- Faster file diffs, and faster Grep and Glob on Windows.
- `/config` search ranks prefix matches first and understands terms like "effort" and "dark".
- `/resume` no longer lists sessions where you only opened a screen such as `/model`.
- Recurring scheduled tasks and `/loop` now run up to 30 days instead of 7.
- More `rm` commands aimed at the root, home or working folder now ask for approval.
- Prompt hooks accept model aliases such as `haiku` or `sonnet`.
- Code Mode gets several speed and display improvements.

## Bug Fixes
- Fixed freezes after compacting a very long conversation and during some WebFetch calls.
- Fixed `ExitWorktree` deleting a worktree that another running session was using.
- Fixed user settings, tasks and plugin lists being lost when several processes wrote at once.
- Fixed `--continue` and `--resume` failing on a last message with a bad timestamp.
- Fixed `/rewind` sometimes restoring an older version of a file.
- Fixed MCP issues: dropped connectors sharing a URL, subagent-declared servers shutting down early, and @-mentioned resources not attaching.
- Fixed `claude -p` exiting 0 silently when output went to a full disk.
- Fixed many Code Mode, LSP, background-agent and self-hosted runner problems.
- Fixed many VS Code extension issues with Enter, Escape and diff Accept/Reject.
