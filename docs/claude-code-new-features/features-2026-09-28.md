# Claude Code — What's New (2026-09-28)

## New Features

- **Claude Opus 5.5 is now available** (`claude-opus-5-5`) as the default Opus model — 1M context window, $4/$20 per Mtok with $0.20/Mtok cache reads.
- **Default model upgraded** on Pro and Team Standard plans from Sonnet to Opus, matching Max, Team Premium, and Enterprise.
- **`/doctor prompt-audit`** (also `/checkup prompt-audit`) audits your CLAUDE.md files, skills, agents, and commands for prompting patterns written for older models.
- **`deniedModels` managed setting** blocks specific models even when `availableModels` allows them; `availableModelsMatch: "exact"` pins allowed entries to exact version strings.
- **`attribution: false`** in `settings.json` hides all commit and PR attribution.
- **`maxProseWidth` setting** caps prose width in wide terminals while tables and code blocks keep full width.
- **`assume_role` on Claude apps gateway Bedrock upstreams** — the gateway calls Bedrock as an assumed IAM role, optionally per developer.
- **MCP URL-mode elicitation** on 2026-07-28 protocol connections lets servers ask Claude Code to open browser-based flows.
- **`/insights` auto mode recommendation** estimates how many permission prompts auto mode could have handled in recent sessions.
- **MCP tool result images** are now also saved to a file so Bash, Read, and other tools can open them.
- **Claude Tag**: Added Slack's native Working indicator, Stop button, and thread title to Claude's threads.
- **VSCode**: Added `/status`, `/sandbox`, `/chrome`, `/export`, `/skills`, and `/plan` typed commands to the panel.

## Improvements

- **Startup latency** reduced: `claude -p` and Claude Code Remote no longer load the interactive UI; auto-mode classifier rules and the Artifact tool load on first use.
- **`/tasks`**, **`/mcp`**, **`/artifacts`**, **`/workflows`**, and most other picker lists gained page-key navigation, mouse wheel scrolling, and click support.
- **Session resume** for very large and compacted sessions is significantly faster.
- **Auto mode denial** message now makes clear that retrying the same action won't help.
- **Compaction spinner** now counts summary tokens as they stream, replacing the percentage bar.
- **`/permissions`**: Focus returns to the rule list after viewing or deleting a rule; delete-rule confirm defaults to No.

## Bug Fixes

- Fixed MCP progress notifications being discarded once a tool call moved to the background.
- Fixed `stdio` MCP servers being left running when the session ended while still starting.
- Fixed Ctrl+C or Ctrl+D pressed twice in most dialogs quitting Claude Code instead of closing the dialog.
- Fixed Windows PowerShell tool allowing `cmd /c rd`, `rmdir`, `del`, or `erase` to delete drive roots and home folders.
- Fixed a recursive `rm` whose target is only command-substitution output running unprompted in auto/bypass mode.
- Fixed cloud sessions occasionally redoing an already-finished step (e.g., posting a duplicate comment) after a worker restart.
- Fixed vim mode cursor placement, count handling, and line-join behavior across many edge cases.
- Fixed `keybindings.json` silently accepting misspelled modifiers like `ctl+k`.
