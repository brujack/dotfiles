# Claude Code — What's New (2026-10-26)

## New Features

- **Monitor tool** added with plugin monitors on Bedrock, Vertex, and Foundry; long foreground sleeps are now blocked in those environments too (2.1.310)
- **`claude_code.safety_event` OpenTelemetry event** emitted for each tool call stopped, prompted, or blocked by a permission rule, safety check, hook, or sandbox (2.1.307)
- **`/claude-api api-version`** command to migrate Claude API code to version `2026-10-21` (2.1.307)
- **`sandbox.allowNestedUserNamespaces`** setting lets sandboxed commands on Linux create user namespaces, enabling Chromium and rootless Podman inside the sandbox (2.1.305)
- **Cloud sessions Enterprise roles**: Cloud sessions and Remote Control permissions added to Enterprise custom roles so Owners can control access by role (2.1.310)
- **Code Review `@claude review stop`** ends an `@claude review always` subscription without starting a new review (2.1.307)

## Improvements

- Auto mode now explains when blocking reads outside the working directories causes shell commands to prompt for permission (2.1.310)
- Memory use of non-interactive sessions (`-p`, Agent SDK) during compaction improved for very large transcripts (2.1.310)
- Linux sandbox startup warning now names Ubuntu's AppArmor restriction on user namespaces and how to lift it (2.1.310)
- `/usage` redesigned: each warning is now a one-line fix naming its source, and `f` applies all fixes (2.1.305)
- Recovery from unparseable tool calls improved: Claude Code retries up to twice before ending the turn (2.1.307)
- Fork subagents launched together are now each told which launch is their own, reducing race conditions (2.1.307)
- MCP consent dialogs improved so an Enter meant for the prompt is less likely to be taken as Accept (2.1.305)
- VSCode: Edit and Write speed improved — wait for new problems after each edit reduced from 1–1.5s to 0.75s (2.1.309)

## Bug Fixes

- Fixed requests failing behind gateways that reject the `effort-2025-11-24` beta value or mid-conversation system messages (2.1.310)
- Fixed background cleanup deleting recently pasted images when `cleanupPeriodDays` is set to a very large value (2.1.310)
- Fixed sandboxed Bash commands on macOS and Linux running shell startup files outside the sandbox (2.1.309)
- Fixed HTTP MCP tool calls being sent twice when the connection closed mid-call (2.1.307)
- Fixed every request failing on Vertex, Bedrock, and other providers when an endpoint rejects tool search (2.1.305)
- Fixed `claude -p` inside cloud sessions reporting "Not logged in" without the session's environment variables (2.1.306)
- Fixed `/effort` and `/autocompact` settings not applying when the model name differed by letter case or `[1m]` tag (2.1.305)
- Fixed Claude Tag posting an approved channel message into a DM by mistake (2.1.309)
