# Claude Code — What's New (2026-11-16)

## New Features
- Added Claude Fable 5.2 (`claude-fable-5-2`) as the default Fable model, with 1M context.
- Added Code Mode, an experimental opt-in where Claude writes JavaScript to call its tools.
- Added `engines["claude-code"]` to `plugin.json` so plugins outside their stated version range are not installed or loaded.
- Added TypeScript hooks-module type checking to `claude plugin validate`, with `--strict` failing on findings.
- Added `--settings <file>` to `claude remote-control`, applied to every session it starts.
- Added fast mode on Vertex in the global, us and eu regions.
- Added an options menu (stop, use credits, upgrade) when a model needs usage credits that are off or used up.
- Added a 30-second progress heartbeat while hooks run long in `claude -p` and SDK sessions.
- Added `.docx` support to Artifact tool asset uploads.
- Added `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES` and `CLAUDE_CODE_RESUME_HINT_COMMAND` environment variables.
- Added a startup warning for Bash allow rules with `*` in a variable's value, and a warning when a plugin's language server cannot start.
- [VSCode] Added prompt suggestions (Tab accepts) and a Console sign-in that creates no API key.

## Improvements
- Improved subagents cut off at the output token limit so they re-answer briefly instead of returning only the end.
- Improved `claude remote-control` to exit 4 when it stops by itself and 69 when it cannot register.
- Improved marketplace and plugin install prompts to warn that plugins can run code on your computer.
- Improved the account email check to also refuse your email as a client identity in scripts, file writes, web fetches and MCP calls.
- Changed sandboxed Bash commands to follow the normal permission flow; set `sandbox.autoAllowBashIfSandboxed: true` to keep prompt-free runs.
- Changed scheduled tasks and `/loop` to ask before running a skill that declares `allowed-tools` or hooks.
- Changed read-only git commands to ask first in repositories outside the project unless added with `--add-dir`.
- Changed `CLAUDE_CODE_MAX_CONTEXT_TOKENS` to also size unrecognized `claude-` model IDs.
- Changed marketplace `ref` to accept the full ID of any commit on a branch or tag.

## Bug Fixes
- Fixed a security issue in zstd-compressed response decoding.
- Fixed several Bash permission gaps where compound commands or allow rules could run without asking, and deny/ask rules not applying after `cd`.
- Fixed Bash sandbox gaps around worktree settings, hooks and the shared git folder.
- Fixed sessions on third-party gateways and Foundry stopping with a context length error instead of compacting.
- Fixed recent turns going missing from a resumed session after an unclean exit.
- Fixed `/security-review` and skill git commands failing in bare-repo and separate-git-dir worktrees.
- Fixed many MCP issues, including stuck background tasks, stale `/mcp` entries and elicitation cancelled in headless mode.
- Fixed Windows `/resume` hiding sessions recorded with a different drive-letter case.
- Fixed `/stats`, `/insights`, `/voice`, `/fast` and `/model` showing wrong or misleading messages.
