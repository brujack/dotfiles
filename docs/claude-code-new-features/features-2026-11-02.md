# Claude Code — What's New (2026-11-02)

Covers versions 2.1.311–2.1.316.

## New Features

- **`CLAUDE_CODE_SUBAGENT_EFFORT`**: new env var sets the default effort level for subagents when nothing else specifies one, instead of inheriting the session's level.
- **`permissions.blockWritesOutsideWorkingDirectories`**: Write, Edit, and NotebookEdit refuse paths outside the working directories in every permission mode.
- **Idle compaction**: VS Code and Claude Desktop's Code tab now auto-compacts conversations exceeding 200K tokens when left idle, using the summary on the next message.
- **`CLAUDE_CODE_DISABLE_ULTRATHINK`**: new env var turns the `ultrathink` keyword off entirely.
- **Pooled group budgets** on Claude apps gateway: one shared monthly budget for a group's members, on top of each member's own limit.
- **`managed.policy_mode: layered`** on Claude apps gateway: every matching policy applies and merges, not just the first match.
- **Click to send**: in fullscreen mode, clicking the "to send now" hint under a queued message sends it immediately.
- **[VSCode]** Sign-in to a Claude apps gateway directly from the chat panel, no terminal needed.
- **[Cloud sessions]** Form card support: fill in or decline forms from MCP servers instead of having requests silently canceled.

## Improvements

- Reduced memory use in long headless and SDK turns running many subagents: the parent no longer retains each subagent's tool results until the session ends.
- `Ctrl+R` prompt history now matches text inside collapsed `[Pasted text]` pills.
- `/code-review` from the Code tab in Claude Desktop or web now shows the findings card instead of a plain-text list.
- `/diff` on large repos runs one fewer full-repository git command per refresh; refreshes are spaced when git is slow.
- SSL certificate errors now name the likely cause (e.g., missing intermediate certificate) and the fix.
- Startup time improved for Pro and Max accounts: two network requests are skipped on launches within an hour of the last check.
- Shell commands that reach their timeout now show the output produced so far and note the command is still running.

## Bug Fixes

- Fixed shell commands left running on macOS and Linux when Claude Code exits (e.g., on credential refusal or cloud session archive).
- Fixed bash aliases with line breaks and functions with dash-prefixed names being garbled in the Bash tool's shell.
- Fixed bash scripts started from the Bash tool stopping after their first command when `SHELLOPTS` is exported.
- Fixed sessions repeatedly failing with "Invalid effort level" when an org's admin caps a model's effort; Claude Code now lowers effort, retries, and reports the level used.
- Fixed `claude -p` exiting with code 0 and no output when startup failed; it now prints the error and exits 1.
- Fixed Bedrock sessions with many images failing with "400 Input is too long" instead of removing older images and compacting.
- Fixed PowerShell hooks not blocking on exit code 2 when the command begins with a type cast, `param`, `using`, or an attribute.

## Deprecations

- Fast mode for Opus 4.8 is deprecated as of October 30, 2026 and will be removed November 30, 2026; migrate to Opus 5.5 to retain the speedup.
