# Claude Code — What's New (2026-10-19)

## New Features

- **`CLAUDE_CODE_AUTO_MODE_MODEL`** lets you choose the model the client-side auto mode classifier uses, independently of the model for server-side auto mode.
- **Idle compaction** now runs automatically in the terminal: conversations over 200K tokens are compacted after ~54 minutes of idle time to avoid reprocessing on the next message. Toggle with `"idleCompaction": false` in settings.json or `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` to adjust the threshold.
- **`CLAUDE_CODE_DISABLE_FILE_MENTIONS`**: when set, `@` file mentions pass only the path to Claude, not the file contents.
- **Fork subagents** (`subagent_type: "fork"`) are now on by default in `claude -p`, the Agent SDK, the desktop app, and VS Code. Use `CLAUDE_CODE_FORK_SUBAGENT=0` to turn off.
- **`CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`** ends a request at a usage limit that resets too far away instead of waiting indefinitely.
- **`%` motion in vim mode**: jump to a matching bracket, alone or with d/c/y operators.
- **`rows` input type for mods**: a multi-line text field where Enter submits and Shift+Enter starts a new line.
- **`--disallow-tools`** and `disallowed_tools` in `claude plugin eval` let you exclude specific built-in tools such as Agent from eval runs.
- **`--shutdown-drain-sec`** for `claude self-hosted-runner orchestrator`: gives in-flight work time to finish on SIGTERM.
- **Idle compaction row in `/config`**: toggle idle compaction on/off from within the session.
- **Cloud sessions banner** now shows why a routine's last run didn't start (e.g., concurrent session limit reached).
- **`classifier_verdict`, `permission_mode`, and `classifier_category`** added to OpenTelemetry `tool_decision` events for richer auto mode observability.

## Improvements

- **Auto mode with the server-side classifier**: conversations too long for the safety check are now compacted instead of every checked tool call being denied.
- **Plugin startup time** is significantly faster with many plugins enabled — far fewer file system calls on load, especially on Windows.
- **Claude Tag admin settings** reorganized into four tabs: Bundles, Connectors, Skills and plugins, and Channels.
- **Claude Tag repository search** now covers up to 100 connected GitHub accounts and finds private repositories past the first 5,000 of a GitHub App install.
- **Background subagents** in the desktop app and VS Code now always run in the background (consistent with terminal behavior).
- **Prompt and agent hooks** now run at most 12 of one event type concurrently; excess hooks queue.
- **`/effort` and `/fast`** in the agents view can now set defaults for new sessions; a bare invocation opens a picker.

## Bug Fixes

- Fixed "Prompt is too long" error when stopping a turn during conversation compaction.
- Fixed requests failing with "diagnostics: Extra inputs are not permitted" after switching to Vertex or Bedrock mid-session.
- Fixed the Read tool loading image files of any size into memory; sources over 128 MB are now refused.
- Fixed `/autocompact` and `/effort` saving to the wrong model when a gateway names Opus 4 or 4.1 with a prefix.
- Fixed plugin marketplaces re-cloning on every refresh and newly installed git plugins showing version "unknown" with reftable ref format.
- Fixed the PowerShell tool not finding commands in a plugin's `bin/` folder.
- Fixed artifact publishes failing when Claude sent an empty list of edits.
- Fixed `claude plugin` subcommands sometimes exiting before a queued settings write finished, losing the change or leaving a `.tmp` file.
- Fixed worktree isolation refusing to create or resume worktrees under git 2.56+ when a stray `.git` file points at a nonexistent directory.
- Fixed a cloud session's cost and usage restarting from zero after the session resumed in a new process.
- Fixed scheduled routine runs showing as Completed after their cloud session stopped unexpectedly.
- Fixed a scheduled routine re-running from the start an hour or more later after a partial failure, which could repeat work such as posting the same report twice.
- Fixed `fable` model alias erroring on the Anthropic API when the newest Fable model is unavailable; Claude Code now retries on the previous version.
- Fixed the Read tool reading binary files (.xlsm, .parquet, .epub, .heic) as text.
- Fixed skills no longer being listed to the model after using `/rewind`.
- Fixed Grep and Glob reporting no matches when the search program failed unexpectedly.
- Fixed Claude Tag (Slack) not delivering HEIC, SVG, TIFF, and BMP image attachments; they now arrive as files in Claude's working files.
- Fixed Claude Tag DMs on a Slack Enterprise Grid ignoring the workspace dropdown.
- Fixed stray characters (e.g., `>0q`) covering prompts in VTE-based terminals older than 0.53 (MATE Terminal on RHEL 8).
- Fixed stray `GOK` text appearing at startup in some versions of iTerm2.
- Fixed vim mode sometimes staying in INSERT after Escape on a slow or busy machine; Esc now works correctly from NORMAL mode in AskUserQuestion fields.
