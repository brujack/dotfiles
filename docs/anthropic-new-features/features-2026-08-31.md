# Anthropic & Claude API — What's New (2026-08-31)

## Model & API Changes
- Beta `files` and `skills` namespaces now use GA response shapes and drop the dated beta header requirement; requests still sending the old headers keep the old shapes.
- Personal keys and service account keys can now be created in the Console, scoped to a workspace or usable across admin/workspace endpoints, tied to the linked account's lifecycle.
- Compliance API session transcript endpoints are now GA for Cowork/Claude Code sessions, and in beta now also cover Claude Science and Microsoft 365 (Excel/PowerPoint/Word/Outlook) sessions.
- Admin API is now available via the `ant` CLI and Python/TypeScript/C#/Go/Java/PHP/Ruby SDKs under `client.beta.organization`, covering org, members, workspaces, keys, rate limits, and encryption keys.
- Computer use tool is now GA as `computer_toolset_20260801` (no beta header), adding batch actions, default zoom, and per-member config.
- A new browser use tool (`browser_toolset_20260801`) drives an app-hosted browser via its accessibility tree rather than full-desktop screenshots.
- Files API and Agent Skills/Skills API are now GA, no longer requiring their respective beta headers.
- Claude Enterprise Admin API user-management endpoints (members, invites, groups, custom roles) are now GA.
- Managed Agents gained: domain allow/block lists for web_search/web_fetch, memory store mounting in self-hosted sandboxes, session budgets, mid-turn advisor models, configurable inference geo, and GitHub-repo skill loading.
- Workbench in the Console has been renamed and redesigned as Playground, supporting all Messages API parameters.
- Claude Opus 5 launched: 1M context window, 128k max output, thinking on by default, same pricing as Opus 4.8; disabling thinking now requires effort ≤ high.
- Claude Sonnet 5 introductory pricing ($2/$10 per MTok) is now permanent, canceling the planned September price increase.
- Fast mode for Claude Opus 4.7 has been removed; requests requesting it now error instead of falling back.
- Claude Opus 4.1 has been retired; all API requests to it now return an error.

## SDK Changes
- Python SDK v1.0 moves its HTTP layer from httpx to a maintained fork (httpx2), requires Python 3.10+, and removes long-deprecated surfaces like the legacy Text Completions API and `temperature`/`top_p`/`top_k` on Messages methods.
- Async client's `.with_raw_response` now requires `await response.parse()`, and `AnthropicBedrock` errors instead of defaulting to `us-east-1` when no region is configured.
- Added support for a beta `updates` thinking display mode and new Organization API endpoints.

## Bug Fixes
- Fixed AWS/Bedrock signing so binary file uploads sign raw request bytes correctly.
- The session event accumulator is now forward-compatible with new event types.
- Fixed file `read` to support a `view_range` on files exceeding the size cap.
- Agent toolset and memory tool now preserve exact file bytes instead of translating newlines.
- Webhook `unwrap()` now requires headers to be passed explicitly.
- The tool runner now continues correctly on a `pause_turn` stop reason.
