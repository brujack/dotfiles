# Anthropic & Claude API — What's New (2026-11-23)

## Model & API Changes

- Claude Fable 5.2 is now available for demanding reasoning and long-horizon agentic work, with a 1M context window, 128k output and always-on adaptive thinking, at a lower price than Fable 5.1.
- Claude Mythos 5.2 has the same capabilities as Fable 5.2 but is open only to verified organizations.
- Fable 5.2 and Mythos 5.2 return a 400 error if you edit the system prompt, tools or earlier messages and then send back later thinking blocks.
- Fable 5.2 and Mythos 5.2 require the new `computer_toolset_20260801` for computer use, and their advisors must also be Fable 5.2 or Mythos 5.2.
- Fast mode for Fable 5.2 gives up to 2.5x output speed when you set `speed: "fast"`, with no beta header needed.
- Claude Haiku 5.5 launched for high-volume work, but manual thinking budgets, sampling parameters, prefill and old computer-use tools now return 400 errors.
- Prompt cache reads on Sonnet 5.5 now cost half as much as before.
- Fast mode for Opus 5.5 is out of preview and needs no beta header, while fast mode for Opus 4.8 is deprecated.
- Linked billing (beta) lets your customers pay for your app's Claude usage through their own organization, using `billing_policy` on each request.
- Message threads (beta) keep a conversation on the server, so each request sends only new messages and gets a faster first token.
- The maximum request size for the Messages and Token Counting APIs went up from 32 MB to 128 MB.
- User profiles let you tag requests by end customer so enforcement actions apply to that customer, and new fields show their restriction status.
- Organization webhooks (beta) report profile restrictions and failures or recoveries of customer-managed encryption keys.
- A new Usage and Cost Analytics API replaces the legacy usage and cost endpoints, which remain supported.
- Organizations can now set an IP allowlist, turn off web fetch, and restrict web fetch domains.
- Older models now carry Anthropic's text watermark, which non-default sampling parameters may weaken.
- Managed Agents can now run entirely self-hosted and can use dynamic multi-agent workflows (beta).

## SDK Changes

- New major SDK versions send API version 2026-10-21 by default, include breaking changes and are now licensed under Apache 2.0 instead of MIT.
- The Python SDK adds billing_policy support, new billing and image-size error codes, Claude Code managed settings, and Claude Tag Bundle updates.
- Several old beta header values are deprecated, and batch requests no longer send the obsolete batches header.
- Structured outputs now build each call's schema from a cached raw schema.

## Bug Fixes

- The Bedrock clients now send the user profile ID in the request body, and models that don't support profiles reject it with a 400 error.
- Spaces in query strings are now encoded as `%20`, so AWS SigV4 signatures match.
- Failed aiohttp connections are no longer reported as timeouts.
- The grep tool now ignores untrusted `rg` binaries and ripgrep config files, skips FIFOs and devices, and stops after a CPU time limit.
- File and memory tools now resolve symlinks safely and read files only through the validated path.
- The session tool runner and EnvironmentWorker no longer run tools for terminated sessions.
- The credentials file now writes correctly on Windows with older Python versions.
