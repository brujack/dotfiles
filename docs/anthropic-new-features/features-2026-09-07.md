# Anthropic & Claude API — What's New (2026-09-07)

## Model & API Changes

- Claude Fable 5.1 and Claude Mythos 5.1 launched with 1M token context by default, 128k max output, always-on adaptive thinking, and prompt cache reads cut to $0.25/MTok.
- Claude Opus 5 launched with 1M context, 128k output, and thinking on by default at the same $5/$25 pricing as Opus 4.8; disabling thinking is now blocked above effort "high".
- `tool_choice` types `any`/`tool` are unsupported on Fable 5.1/Mythos 5.1 (use strict tool use or structured outputs instead).
- Thinking-block preservation rules tightened on Fable 5.1: blocks only replay to the same or newer model, and history changes can now trigger a 400 error.
- Per-message effort changes and turn-scoped system messages are now in beta, letting you adjust behavior mid-conversation without invalidating the prompt cache.
- Computer use and the new browser use toolset are both out of beta (no header required); Files API, Agent Skills/Skills API, and Enterprise user-management endpoints are also out of beta.
- Managed Agents gained session budgets, advisor models, configurable inference geography, GitHub-sourced skills, and domain allow/block lists for web_search/web_fetch.
- Inference hooks (beta) let Enterprise orgs gate every prompt through an external allow/deny server before inference runs.
- Sonnet 5 pricing is now permanently $2/$10 per MTok; Opus 4.1 has been retired and fast mode removed from Opus 4.7.
- Personal and service-account API keys can now be created directly in the Console, and Compliance API session-transcript endpoints (Cowork, Claude Code, local/remote sessions) are broadly out of beta.

## SDK Changes

- Python SDK v1.0 replaces `httpx` with a maintained `httpx2` fork, requires Python 3.10+, and drops the legacy Text Completions API plus `temperature`/`top_p`/`top_k` on Messages methods.
- `client.beta.files` and `client.beta.skills` no longer send beta headers and now match the GA shapes; `client.beta.skills.delete()` removes all versions, and `BetaSkill` was renamed `BetaContainerSkill`.
- Admin API is now available via the `ant` CLI and Python/TypeScript/Go/Java/Ruby/C#/PHP SDKs under `client.beta.organization`.
- Python SDK 1.4.0 adds Claude Tag usage-report breakdowns, typed organization compliance settings, and workspace ID support on more endpoints.

## Bug Fixes

- Python SDK now raises a clear error if a legacy `httpx` object is passed where `httpx2` is expected.
- Fixed a custom-code merge issue in messages resources.
- Fixed AWS `base_url` resolution from `aws_region` under `skip_auth` and `with_options`.
- Batches results were missing from GA raw/streaming response wrappers; now added.
- The client now correctly derives a multipart filename for file tuples passed without one.
