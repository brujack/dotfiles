# Anthropic & Claude API — What's New (2026-08-03)

## Bug Fixes
- The Python SDK now supports both MCP SDK v2 and v1 instead of requiring v1 only.
- The Python SDK's `mcp` extra was pinned to below version 2 to prevent compatibility issues before v2 support landed.
