# Anthropic & Claude API — What's New (2026-08-17)

## Model & API Changes
- Claude Opus 5 launched with a 1M token context window, 128k max output tokens, thinking on by default, and disabling thinking is now blocked above effort level high.
- Claude Sonnet 5 launched with a 1M token context window, adaptive thinking on by default, manual thinking budgets removed, and a new tokenizer producing roughly 30% more tokens for the same text.
- Claude Fable 5 and Claude Mythos 5 launched with 1M token context, always-on adaptive thinking, and safety-classifier refusals now surfaced via a dedicated stop reason.
- Sonnet 5's introductory pricing is now permanent; the planned price increase was cancelled.
- Claude Opus 4.1, Sonnet 4, and Opus 4 have been retired and now return errors on every request.
- Fast mode was removed for Opus 4.6 and 4.7; only Opus 4.8 and Opus 5 still support it.
- API rate limits were raised broadly, with Sonnet and Haiku now matching Opus limits and usage tiers consolidated to three.
- Managed Agents gained session spend budgets, an advisor model for mid-turn guidance, configurable inference geography, GitHub-hosted skill loading, and per-session configuration overrides.
- Managed Agents also added lifecycle webhooks (environment, memory store, agent, deployment), streaming event deltas, and backward-paginated session listings.
- The Compliance API can now return full session transcripts for Cowork and Claude Code, both local and cloud, for Enterprise orgs.
- Inference hooks entered beta, allowing Enterprise orgs to route prompts through their own security server for allow/deny verdicts.
- The Admin API gained beta support for managing organization members, groups, and custom roles.
- API keys can now be created with an expiration date, with email warnings sent beforehand.
- The legacy Workbench and its experimental prompt-generation endpoints were sunset.
- MCP tunnel management moved to a new endpoint on the main Claude API.

## SDK Changes
- The Python SDK added support for dream creation with configurable output behavior (new memory store vs. updating the input store in place).
- The Python SDK exposed beta.messages.parse, stream, and tool_runner on the Bedrock and Vertex clients.
- Major SDKs (Python, TypeScript, Go, Java, Ruby, PHP, C#, CLI) switched memory store calls to a new beta header with updated listing semantics.

## Bug Fixes
- Fixed SigV4 signing blocking the event loop in async Bedrock/AWS clients.
- Fixed empty ANTHROPIC_API_KEY/ANTHROPIC_AUTH_TOKEN values being treated as set instead of unset.
- Fixed PathLike file contents not being read when passed inside a file tuple.
- Fixed streaming accumulation to apply all message_delta fields and keep omitted content block fields unset.
- Fixed the request transform running more than once inside messages.stream().
- Fixed missing input_json events for server tool use blocks during streaming.
- Fixed tool path handling to reject symlink loops and skip special skill-archive members.
- Fixed token exchange staying incorrectly bound after a client copy() call.
