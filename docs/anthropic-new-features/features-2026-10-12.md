# Anthropic & Claude API — What's New (2026-10-12)

## Model & API Changes
- Claude Haiku 5.5 (`claude-haiku-5-5`) launched with a 1M context window, 128k max output, and adaptive thinking via the `effort` parameter.
- Code written for Haiku 4.5 can break on Haiku 5.5, because `budget_tokens`, `temperature`, `top_p`, `top_k`, prefill, and `computer_20250124` can each return a 400 error.
- Claude Sonnet 5.5 (`claude-sonnet-5-5`) launched; to turn off up-front thinking, send `thinking: {"type": "between_tools"}` instead of `"disabled"`.
- Sonnet 5.5 returns a 400 error for forced tool use (`tool_choice` types `any` and `tool`), and it rejects the earlier `computer_20251124` tool on the Claude API and Google Cloud.
- Thinking blocks from Sonnet 5.5 work only in the account that produced them or a linked account. The API drops them from any other account.
- Claude Opus 5.5 (`claude-opus-5-5`) launched at $4/$20 per MTok, with a 1M context window, 128k max output, and always-on adaptive thinking.
- Opus 5.5 returns a 400 error if you disable thinking or send `tool_choice` types `any` or `tool`. Computer use on it needs `computer_toolset_20260801`.
- Claude Fable 5.1 and Mythos 5.1 launched at $10/$50 per MTok, with cache reads cut to $0.25 per MTok.
- Sonnet 5.5 cache reads dropped from $0.20 to $0.10 per MTok.
- Claude Sonnet 4.5 is deprecated, with retirement on the Claude API scheduled for November 30, 2026.
- Tools can now be defined inside a mid-conversation system message (beta, `inline-tools-2026-09-15` header), so you can change tools without invalidating the prompt cache.
- The Messages API can compact a conversation on demand (beta, `compact-2026-09-04` header) and returns a signed compaction block.
- Cache diagnostics is out of beta and no longer needs its beta header. Responses now always include `diagnostics`, which is `null` when you didn't opt in.
- The API now stores a request's cache fingerprint only when the request includes the `diagnostics` object.
- Refusals that arrive before any output are billed again for the `bio`, `frontier_llm`, and `reasoning_extraction` categories.
- The Models API adds `line`, `capabilities.server_tools`, and `capabilities.thinking.types.disabled`.
- Managed Agents gain dynamic workflows (beta), `auto` permission policies, and `allowed_hosts` enforcement on `web_search` and `web_fetch`.
- Managed Agents `web_fetch` now fetches only URLs that already appeared in the session.

## SDK Changes
- The Python and TypeScript SDKs add beta toolset classes for the browser use and computer use tools.
- Admin API methods are out of beta and live under `client.organization` and `ant organization`.
- The Python SDK adds `claude-haiku-5-5`, typed computer and browser toolset tool calls, and Managed Agents workflows, multiagent configuration, and thread status filtering.
- The Python SDK adds `include_default` on list workspaces, `display_name` on RBAC roles (with `name` deprecated), and `url_sources` on the Managed Agents `web_fetch` config.
- The `ant` CLI adds `ant apply` to manage resources as code, and `ant beta:sessions connect` to attach a terminal to a Managed Agents session.

## Bug Fixes
- The Python SDK now sends empty strings in query params and multipart forms.
- The Python SDK now sends the beta header by default when listing spend limits.
- The Python SDK memory tool now keeps a local edit made after a memory upload whose response was lost.
