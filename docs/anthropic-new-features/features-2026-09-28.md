# Anthropic & Claude API — What's New (2026-09-28)

## Model & API Changes

- Claude Opus 5.5 launched: 1M context window by default, 128k max output tokens, always-on adaptive thinking, priced at $4/$20 per MTok; thinking can't be disabled and `tool_choice` types `any`/`tool` return 400 errors (use `auto` with strict tool use instead).
- Computer use on Opus 5.5 requires the new `computer_toolset_20260801` toolset on the API and Google Cloud (the older `computer_20251124` tool now 400s there, though it still works on Bedrock).
- Fast mode (research preview) is now available for Opus 5.5 on the Claude API.
- Tools can now be added or modified mid-conversation via a `tool_addition` block (beta), letting you change a tool's schema or swap server tool versions without invalidating the prompt cache; combined with the MCP connector beta header, this also supports pinning MCP toolset listings.
- Billing now applies to certain pre-output refusals (categories "bio", "frontier_llm", "reasoning_extraction") that were previously unbilled; other refusal categories remain unbilled.
- Cache diagnostics is now out of beta and no longer needs a beta header; responses always include a `diagnostics` field (null if not requested).

## SDK Changes

- Python SDK 1.8.0 adds support for Claude Opus 5.5, inline tool definitions, and MCP tool-list pinning (beta).
- The Python, TypeScript, Go, Java, Ruby, and C# SDKs updated `client.beta.files`/`client.beta.skills` to drop their beta headers and match the now-stable `client.files`/`client.skills` shapes; `client.beta.skills.delete()` now deletes a Skill and all its versions, and `BetaSkill` was renamed `BetaContainerSkill`.
- Python SDK reached v1.0: its HTTP layer moved from `httpx` to a compatible fork `httpx2`, it now requires Python 3.10+, and it removes long-deprecated surface (legacy Text Completions API, `temperature`/`top_p`/`top_k` on Messages methods, and client-side `compaction_control`).

## Bug Fixes

- Managed Agents events now share a single `evaluated_permission` enum across `agent.tool_use` and `agent.mcp_tool_use`.
- Fixed a Python 3.13 crash on exit when a stream was left open.
- `add_tools()` now takes effect immediately instead of being delayed.
- The tool runner no longer includes reply-only parameters in its compaction request.
