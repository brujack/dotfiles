# Anthropic & Claude API — What's New (2026-09-21)

## Model & API Changes

- Compact endpoint now available in beta, letting you summarize a conversation on demand via a signed compaction block that can replace prior messages while preserving preserved thinking.
- Managed Agents permission policies gained an `auto` mode where the server itself decides to allow, deny, or pause each tool call for approval.
- Launched Claude Fable 5.1 and Claude Mythos 5.1 with 1M token context, 128k max output, always-on adaptive thinking, and cheaper cache reads ($0.25/MTok).
- On Fable 5.1/Mythos 5.1, `tool_choice` types `any`/`tool` are no longer supported (400 error), and preserved thinking blocks are only valid for the producing model or newer.
- Per-message effort changes and turn-scoped system messages (`clear_at`) are now in beta, letting you adjust effort or add one-turn reminders without invalidating the prompt cache.
- `thinking.display` gained an `"updates"` mode that surfaces short progress text between tool calls instead of full reasoning.
- Computer use tool is now out of beta (`computer_toolset_20260801`) with batch actions and default zoom; a new browser use tool (`browser_toolset_20260801`) was added for viewport-level browser control.
- Files API, Agent Skills/Skills API, and Claude Enterprise user-management endpoints are all now out of beta and no longer require their respective beta headers.
- You can now restrict `web_search`/`web_fetch` domains via `allowed_domains`/`blocked_domains`, and set per-session spend budgets and advisor models for Managed Agents.
- Sonnet 5's introductory pricing ($2/$10 per MTok) is now permanent; the planned September price increase was cancelled.
- Added `anthropic-workspace-id` response header to identify which workspace handled a request.

## SDK Changes

- Python SDK hit v1.0, moving its HTTP layer from `httpx` to `httpx2` and dropping deprecated surface (legacy Text Completions API, `temperature`/`top_p`/`top_k` on Messages, client-side `compaction_control`).
- Python SDK 1.6.0 added a `compact_before_next_turn()` helper to the tool runner and support for async credential token providers.
- `client.beta.files`/`client.beta.skills` now mirror the non-beta clients and no longer send beta headers by default; `client.beta.skills.delete()` now deletes all versions of a Skill.
- Admin API is now available in the `ant` CLI and Python/TypeScript/C#/Go/Java/PHP/Ruby SDKs under `client.beta.organization`.
- New `ant apply` command manages agents, environments, skills, and deployments as code via a committable lockfile.

## Bug Fixes

- Retry-After header values above 60 seconds are now honored, and invalid values fall back to default backoff.
- Fixed async client connection retries so they no longer block the coroutine retry loop.
- Multiple `anthropic-beta` header values are now joined with a comma and no space.
- Client no longer raises `TypeError` when parsing `X | Y` union fields with unknown data.
- Bedrock client now raises a proper API error for eventstream exception/error frames.
