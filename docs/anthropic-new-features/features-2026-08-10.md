# Anthropic & Claude API — What's New (2026-08-10)

## Model & API Changes

- Claude Opus 5 launched with a 1M token context window, 128k max output tokens, and thinking enabled by default; disabling thinking is now restricted to effort levels of high or below.
- Claude Sonnet 5 launched with a 1M context window and adaptive thinking on by default; manual extended thinking budgets and non-default sampling parameters now return errors, and it uses a new tokenizer producing ~30% more tokens for the same text.
- Claude Fable 5 and Claude Mythos 5 launched with always-on adaptive thinking, a 1M context window, and safety classifiers that can return a `refusal` stop reason.
- Claude Opus 4.1, Sonnet 4, and Opus 4 have been retired and now return errors on all requests.
- Fast mode has been removed for Claude Opus 4.6 and 4.7; migrate to Opus 4.8 or Opus 5 to keep using it.
- Managed Agents sessions now support hard spend budgets, an "advisor" model role for mid-turn strategic guidance, configurable inference geography, and automatic skill-loading from a GitHub repo's `.claude/skills` directory.
- Managed Agents sessions can now be seeded with up to 50 initial events at creation, support per-session config overrides, and allow optional version checks on agent updates.
- Managed Agents added scheduled (cron-based) deployments and environment-variable credential injection into agent sandboxes.
- Inference hooks are now in beta, letting Enterprise orgs route governed prompts through their own security server for allow/deny verdicts before inference.
- Rate limits for Sonnet and Haiku were raised to match Opus across a newly consolidated three-tier system (Start, Build, Scale).
- The `fallbacks` parameter now supports a `"default"` mode that applies Anthropic's recommended fallback models by refusal category.
- The code execution tool gained a new version with REPL state persistence (minimum requirement for programmatic tool calling) and a version disclosing its 90-second per-cell execution limit.
- Web search and web fetch tools added a `response_inclusion` parameter to drop consumed result blocks for agentic workflows.
- API keys can now be created with an expiration date, with email warnings sent before keys expire.
- The legacy Workbench and its experimental prompt-generation/improvement/templatizing endpoints are being retired.

## SDK Changes

- Python SDK (and equivalents in TypeScript, Go, Java, Ruby, PHP, C#) added support for the `mid-conversation-tool-changes` beta, session budgets, the advisor role, inference location pinning, and GitHub skill auto-loading.
- SDKs now send the `agent-memory` beta header on memory store calls instead of the older `managed-agents` header.
- Retired Opus 4.1 model references were removed from the Python SDK, and all dependencies now have major version constraints pinned.
