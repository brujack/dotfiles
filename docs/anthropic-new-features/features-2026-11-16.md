# Anthropic & Claude API — What's New (2026-11-16)

## Model & API Changes

- **Claude Fable 5.2** (`claude-fable-5-2`) is out for hard reasoning and long-running agent work, with a 1M-token context, 128k max output, always-on adaptive thinking and lower prices than Fable 5.1.
- **Claude Mythos 5.2** has the same capabilities but is only available to organizations verified through Anthropic's programs.
- On Fable/Mythos 5.2, editing the system prompt, tools or earlier messages and then sending back later thinking blocks returns a 400 error.
- Fable/Mythos 5.2 can read thinking blocks from other models, but their own thinking blocks are dropped when a conversation moves to any other model.
- Fable/Mythos 5.2 need the `computer_toolset_20260801` toolset for computer use; the older tool now returns a 400 error everywhere except Bedrock.
- With the advisor tool, a Fable/Mythos 5.2 executor accepts only Fable/Mythos 5.2 as its advisor.
- Fast mode for Fable 5.2 works by setting `speed: "fast"`, with no beta header.
- Fast mode for Opus 5.5 is generally available, while fast mode for Opus 4.8 is deprecated.
- **Claude Haiku 5.5** has launched, but sampling parameters, prefill, manual thinking budgets and the old computer-use tool can return 400 errors on it.
- Prompt cache reads on Sonnet 5.5 now cost half as much.
- Message threads (beta) keep the conversation on the server, so each request sends only the new messages.
- The maximum request size for the Messages and Token Counting APIs is now 128 MB, up from 32 MB.
- The new Usage and Cost Analytics API (beta) replaces the older usage and cost endpoints, which are now legacy.
- User profiles let you tag requests by end customer, so a safety enforcement action can apply to one customer instead of your whole organization.
- Organization webhooks (beta) notify you when one of those customers is restricted or banned.
- Admins can turn off web fetch or limit its domains, and Managed Agents follow those settings.
- Managed Agents can now be self-hosted, can run dynamic multi-agent workflows (beta), and can export OpenTelemetry traces.
- The Models API now reports whether each model supports `between_tools` thinking.
- A Console IP allowlist (beta) refuses requests from addresses not on your list.

## SDK Changes

- New major SDK and CLI versions send the new API version by default, include breaking changes and switch to the Apache 2.0 license.
- The Python and TypeScript SDKs add beta classes for browser-use and computer-use tools.
- The Python SDK adds the Fable/Mythos 5.2 model IDs and the user-profile program-status webhook event.
- The Python SDK adds parent-organization filtering to usage and cost reports, and Claude Tag metrics and settings.

## Bug Fixes

- Bedrock and Vertex clients now handle `;` in model IDs correctly and refuse empty or malformed model, project or region values.
- Google Cloud clients now percent-encode path segments and refuse empty IDs.
- Bedrock and Vertex now have the `parse` and `count_tokens` methods on their raw and streaming response wrappers.
- Bedrock request signing no longer fails with a `KeyError` when the request has no `Connection` header.
- Bedrock, Bedrock Mantle and Vertex clients now read `ANTHROPIC_CUSTOM_HEADERS`.
- API errors can now be pickled and copied.
- Foundry clients no longer raise an error on `copy` or `with_options` when `ANTHROPIC_FOUNDRY_RESOURCE` is set.
- Structured output schemas now keep `const` instead of dropping it.
