# Anthropic & Claude API — What's New (2026-11-09)

## Model & API Changes

- Message threads (beta) keep conversation state on the server so later requests send only new messages, cutting request size and time to first token.
- Max request size for the Messages and Token Counting APIs rose from 32 MB to 128 MB on the first-party API.
- Claude Haiku 5.5 launched with a 1M context window, 128k max output, and adaptive thinking, but it returns 400 errors for `budget_tokens`, sampling parameters, prefill, and `computer_20250124`.
- Claude Sonnet 5.5 launched, and it rejects forced tool use, requires `thinking: {"type": "between_tools"}` to skip up-front thinking, and drops thinking blocks sent from a different account.
- Prompt cache reads on Sonnet 5.5 dropped to $0.10 per million tokens.
- Fast mode for Opus 4.8 is deprecated and will error after November 30, so migrate to Opus 5.5.
- Fast mode for Opus 5.5 is out of research preview and no longer needs the beta header.
- Claude Sonnet 4.5 is deprecated, with retirement scheduled for November 30.
- API version 2026-10-21 was released, along with new major SDK and CLI versions that default to it.
- User profiles let you identify end customers per request, so enforcement actions can target one customer instead of your whole organization.
- User profiles now expose `enforcement_status` and `enforcement_actions` fields, plus a list filter.
- The Models API now reports `line`, `capabilities.server_tools`, `capabilities.thinking.types.disabled`, and `capabilities.thinking.types.between_tools`.
- The Usage and Cost Analytics API (beta) reports token usage and cost, and the older Usage and Cost API is now legacy.
- Refusals that arrive before any output are billed again for the `bio`, `frontier_llm`, and `reasoning_extraction` categories.
- The Admin API adds organization webhooks and IP allowlisting (both beta), a beta call to sign members out everywhere, and a Claude Tag API (beta).
- Organization admins can disable web fetch or restrict its domains in the Console.
- Managed Agents gained dynamic workflows (beta), and web fetch now only fetches URLs that already appeared in the session.
- Managed Agents web tools now honor environment `allowed_hosts` and organization domain settings.
- OpenTelemetry export (beta) traces Messages API requests and Managed Agents sessions.
- Claude Models on Google Cloud (Anthropic managed) launched, including fast mode for Opus 5.5.

## SDK Changes

- All SDKs and the `ant` CLI shipped breaking major versions, and they are now licensed under Apache 2.0.
- Python and TypeScript SDKs added beta browser-use and computer-use toolset classes that run the tool loop for you.
- The Admin API organization methods are out of beta and live under `client.organization` and `ant organization`.
- Python SDK added error classes for HTTP statuses and API error codes, plus `error_code`, `details`, and `api_message` on `APIStatusError`.
- Python SDK added GA analytics, spend limit, and RBAC methods, an `ids` filter on listing workspaces, and `user_profile_id` on External Keys and Workspaces.
- Python SDK refuses credential config files that group or others can write.

## Bug Fixes

- Bedrock clients now raise a `ValueError` for empty, `.`, or `..` model names instead of sending the request.
- Vertex clients percent-encode the model, project ID, and region in request paths.
- Bedrock clients keep a custom `http_client` and `aws_profile` on copies made with `copy` and `with_options`.
- Python SDK response parsing and pydantic v1 union validation are now thread-safe.
- The memory tool no longer renames or deletes the `/memories` directory.
- `OverloadedError` and `ServiceUnavailableError` now subclass `InternalServerError`.
