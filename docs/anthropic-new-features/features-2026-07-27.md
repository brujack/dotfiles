# Anthropic & Claude API — What's New (2026-07-27)

## Model & API Changes
- Claude Opus 5 launched with a 1M token context window, 128k max output tokens, thinking on by default, and the same pricing as Opus 4.8; disabling thinking now only works at effort high or below.
- Claude Sonnet 5 launched with a 1M token context window, adaptive thinking on by default (manual extended thinking budgets are removed and error), and a new tokenizer producing roughly 30% more tokens for the same text.
- Claude Fable 5 and Claude Mythos 5 launched with 1M token context, always-on adaptive thinking, the same new tokenizer, and refusal handling via `stop_reason: "refusal"` (no charge when no output was generated).
- Claude Opus 4.8 launched with a 1M token context window by default and support for mid-conversation system messages, letting you inject instructions mid-session without breaking prompt cache.
- Mid-conversation tool changes are now in beta, allowing tools to be added or removed between turns while preserving cache.
- The `fallbacks` parameter gained a "default" mode that applies Anthropic's recommended fallback models by refusal category.
- Fast mode has been removed for Opus 4.7 and 4.6; requests using it either error (4.7) or silently run at standard speed (4.6).
- API rate limits were raised across Sonnet and Haiku to match Opus, and usage tiers were consolidated into three (Start, Build, Scale).
- Claude Sonnet 4 and Claude Opus 4 have been retired; Opus 4.1 is deprecated with retirement scheduled soon.
- The code execution tool gained a new version with REPL state persistence, required for programmatic tool calling.
- The web search and web fetch tools gained a `response_inclusion` parameter to drop consumed result blocks for agentic workflows.
- API keys can now be created with an expiration date, with email warnings sent before expiry.
- A new Admin API (beta) supports managing Claude Enterprise organization members, groups, and custom roles.

## SDK Changes
- Added support for the `claude-opus-5` model, tool addition/removal blocks, and `tool_change` events.
- Expanded client-side fallback credit token types and added the server-side fallbacks "default" option.
- Added a new stop reason, `model_context_window_exceeded`.
- Added support for Managed Agents model effort settings, initial session events, and thread delta streaming.
- Added support for a new refusal category.
- Added Workload Identity Federation, interactive OAuth, and auth profiles to the client.

## Bug Fixes
- Fixed handling of binary files in the agent toolset's read/edit operations.
- Fixed credential handling when using `AnthropicAWS.copy()`.
