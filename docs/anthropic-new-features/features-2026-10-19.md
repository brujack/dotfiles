# Anthropic & Claude API — What's New (2026-10-19)

## Model & API Changes

- Claude Haiku 5.5 (`claude-haiku-5-5`) launched with a 1M context window, 128k max output, and adaptive thinking.
- Haiku 5.5 returns 400 errors for `budget_tokens`, `temperature`, `top_p`, `top_k`, assistant prefill, and `computer_20250124`.
- Claude Sonnet 5.5 (`claude-sonnet-5-5`) launched on the Claude API and all major cloud platforms.
- Sonnet 5.5 returns a 400 for forced tool use (`tool_choice` types `any` and `tool`), and up-front thinking is turned off with `thinking: {"type": "between_tools"}` instead of `"disabled"`.
- Sonnet 5.5 thinking blocks work only in the account that produced them or a linked account, and the API drops them otherwise.
- Claude Opus 5.5 (`claude-opus-5-5`) launched with a 1M context window, 128k max output, always-on adaptive thinking, and $4 / $20 per MTok pricing.
- Opus 5.5 returns a 400 if you disable thinking or set `thinking.type` to `enabled`, and it also rejects `tool_choice` types `any` and `tool`.
- Fast mode for Opus 5.5 is out of research preview and no longer needs the beta header.
- Fast mode for Opus 5 and Opus 4.8 remains in research preview.
- Prompt cache reads on Sonnet 5.5 dropped to $0.10 per million tokens.
- Billing resumed for refusals with no output in the `bio`, `frontier_llm`, and `reasoning_extraction` categories.
- Cache diagnostics is out of beta, and responses from `POST /v1/messages` always include a `diagnostics` field (null if you didn't opt in).
- On-demand conversation compaction is in beta with the `compact-2026-09-04` header.
- Tools can be defined inside a mid-conversation system message, in beta with the `inline-tools-2026-09-15` header.
- The Models API now reports `capabilities.server_tools`, `capabilities.thinking.types.disabled`, and a `line` field for model grouping.
- OpenTelemetry export is in beta for Messages API requests and Managed Agents sessions.
- Managed Agents gained dynamic workflows (beta), an `auto` permission policy, and scheduled deployments on Claude Platform on AWS.
- Managed Agents `web_fetch` now fetches only URLs that already appeared in the session, and limited-networking environments apply `allowed_hosts` to web tools.
- Claude Sonnet 4.5 is deprecated, with retirement scheduled for November 30, 2026.
- Admin API methods are out of beta under `client.organization` and `ant organization`.

## SDK Changes

- Python SDK adds native OpenTelemetry tracing, which activates automatically if you register a global tracer provider.
- You can disable tracing with `open_telemetry=False` or `ANTHROPIC_OPEN_TELEMETRY=false`.
- Python and TypeScript SDKs add beta toolset classes for the browser use and computer use tools.
- Python SDK adds the `speed` parameter and `usage.speed` to Messages, and some models need a beta header to use it.
- Python SDK adds `between_tools` to the thinking types in model capabilities.
- Python SDK adds `execution_identity` for Managed Agents and telemetry destination endpoints in the Admin API.
- The `ant` CLI adds `ant beta:sessions connect` to attach a terminal to a Managed Agents session.

## Bug Fixes

- Python streaming helpers now pass unknown event types through instead of failing.
- Python streaming no longer raises "Unexpected event order" for an event before `message_start`.
- Python client now closes dropped streams without waiting for the collector.
