# Anthropic & Claude API — What's New (2026-10-26)

## Model & API Changes
- Claude Haiku 5.5 (`claude-haiku-5-5`) launched with a 1M context window, 128k max output, and adaptive thinking, but code written for Haiku 4.5 can break (`budget_tokens`, `temperature`/`top_p`/`top_k`, prefill, and `computer_20250124` return 400s).
- Claude Sonnet 5.5 (`claude-sonnet-5-5`) launched with breaking changes from Sonnet 5: use `thinking: {"type": "between_tools"}` instead of `"disabled"`, forced `tool_choice` (`any`/`tool`) returns 400, and `computer_20251124` is no longer accepted on the Claude API and Google Cloud.
- Claude Opus 5.5 (`claude-opus-5-5`) launched with a 1M context window, 128k max output, always-on adaptive thinking, and pricing of $4/$20 per MTok.
- Sonnet 5.5 thinking blocks only work in the account that produced them (or a linked one); other accounts' blocks are silently dropped.
- Sonnet 5.5 prompt cache reads dropped from $0.20 to $0.10 per million tokens.
- API version 2026-10-21 was released, and the new SDK and CLI versions send it by default.
- Fast mode for Opus 5.5 is out of research preview and no longer needs the `fast-mode-2026-02-01` beta header (Opus 5 and 4.8 still need it).
- Cache diagnostics is out of beta and no longer needs its beta header; `POST /v1/messages` responses now always include `diagnostics` (null if not requested).
- Refusals with `stop_details.category` of `bio`, `frontier_llm`, or `reasoning_extraction` are billed again, even before any output.
- The Models API gained `line`, `capabilities.server_tools`, `capabilities.thinking.types.disabled`, and `capabilities.thinking.types.between_tools`.
- User profiles are generally available (`/v1/user_profiles`), so you can attribute requests to end customers. New `enforcement_status` and `enforcement_actions` fields and an `enforcement_status[]` filter show restrictions and bans.
- Org webhooks (beta) fire when a user profile is restricted or banned, and again when it's lifted.
- The Claude Tag API is in beta for Enterprise organizations.
- Claude Models on Google Cloud (Anthropic managed) launched, with fast mode for Opus 5.5.
- OpenTelemetry export is in beta for Messages API requests and Managed Agents sessions.
- Managed Agents gained dynamic workflows (beta), and `web_fetch` now only fetches URLs already seen in the session. It also follows org-level and `allowed_hosts` domain restrictions.
- Org admins can turn off web fetch in the Console, and doing so makes requests that include the tool fail with a 400.
- Claude Sonnet 4.5 is deprecated, with retirement scheduled for November 30, 2026.

## SDK Changes
- Python 2.0.0, TypeScript 1.0.0, C# 13.0.0, Go 2.0.0, Java 3.0.0, PHP 1.0.0, Ruby 2.0.0, and ant CLI 2.0.0 default to the new API version, include other breaking changes, and are now Apache 2.0 licensed.
- Python and TypeScript SDKs added beta browser use and computer use toolset classes that run the tool loop for you.
- Admin API methods are out of beta under `client.organization` and `ant organization`, with the beta paths kept.
- The Python SDK added Claude Tag endpoints, message threads, usage and cost reports by dimension, and workspace rate-limit updates.
- The Python SDK now yields server-sent events with unrecognized event names.

## Bug Fixes
- Python SDK: tool runner `set_messages_params()` now keeps `betas`, `user_profile_id`, and `workspace_id` when omitted, and handles `tools` given as definitions correctly.
- Python SDK: `append_messages()` now leaves the history to the caller.
- Python SDK: the Bedrock, Mantle, and Google Cloud clients keep workspace and user profile IDs set in `default_headers`.
- Python SDK: Google Cloud user profile requests now go to the organization endpoint.
