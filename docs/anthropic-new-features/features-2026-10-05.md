# Anthropic & Claude API — What's New (2026-10-05)

## Model & API Changes
- Claude Sonnet 5.5 (`claude-sonnet-5-5`) is available on the Claude API, Bedrock, Claude Platform on AWS, Google Cloud, and Microsoft Foundry.
- Moving from Sonnet 5 to 5.5 can break code: disabling thinking now requires `thinking: {"type": "between_tools"}`, forced `tool_choice` (`any`/`tool`) returns a 400, and the old `computer_20251124` tool is rejected on the Claude API and Google Cloud.
- Sonnet 5.5 thinking blocks work only in the account that produced them or a linked account; other accounts' blocks are silently dropped.
- Claude Opus 5.5 (`claude-opus-5-5`) launched with a 1M context window, 128k max output, always-on adaptive thinking, and $4/$20 per MTok pricing.
- Opus 5.5 returns a 400 for `thinking: disabled` or `enabled` and for forced `tool_choice`, so control thinking depth with `effort`. Fast mode is in research preview.
- Claude Sonnet 4.5 is deprecated, with retirement on the Claude API scheduled for November 30, 2026; migrate to Sonnet 5.5.
- Refusals that arrive before any output are billed again when `stop_details.category` is `bio`, `frontier_llm`, or `reasoning_extraction`.
- Cache diagnostics is GA with no beta header. Add the `diagnostics` object to opt in; responses now always include `diagnostics`, which is `null` if you didn't opt in.
- Inline tool definitions inside mid-conversation system messages are in beta (`inline-tools-2026-09-15`). They let you add or change tools without invalidating the prompt cache.
- On-demand conversation compaction is in beta (`compact-2026-09-04`); it returns a signed `compaction` block to send in place of the summarized messages.
- Claude Fable 5.1 and Mythos 5.1 launched with 1M context and cache reads at $0.25/MTok.
- Fable 5.1 and Mythos 5.1 add per-message effort changes, turn-scoped system messages, and `thinking.display: "updates"`, all in beta.
- Managed Agents permission policies gain `auto`, where the server evaluates each tool call.
- Personal and service-account API keys are available in the Console.
- Compliance API Activity Feed no longer returns file names, document names, or artifact titles.

## SDK Changes
- Python SDK v1.0 moves from `httpx` to `httpx2`, requires Python 3.10+, and removes the legacy Text Completions API and `temperature`/`top_p`/`top_k` on Messages methods.
- Python SDK v1.0 changes the async client's `.with_raw_response` to need `await response.parse()`, and `AnthropicBedrock` now errors when no AWS region is set.
- `client.beta.files` and `client.beta.skills` no longer send beta headers across the SDKs, and `BetaSkill` is renamed `BetaContainerSkill`.
- The Admin API is available in the `ant` CLI and SDKs under `client.beta.organization`.
- `ant apply` manages agents, environments, skills, and other resources from repo files, and `ant beta:sessions connect` attaches your terminal to a Managed Agents session.
- Python SDK adds `claude-sonnet-5-5`, the `between_tools` thinking type, and optional tool calls while the reply streams.
- Python SDK adds a list spend limits endpoint, Plugins and Plugin Marketplaces in the Admin API, and Organization API endpoints now GA.

## Bug Fixes
- Python SDK credentials loading refuses config files that group or others can write.
- Auto-paging now continues past an empty page while `next_page` is set.
- The session tool runner stops after any idle event that ends the turn.
- `stream()` and `parse()` now accept `diagnostics`.
- `between_tools` thinking degrades to disabled on fallback hops.
- File uploads without a name no longer send a placeholder filename.
- Memory store `description`, `metadata`, and `archived_at` are now typed as required.
