# Anthropic & Claude API — What's New (2026-08-24)

## Model & API Changes

- The Python SDK's HTTP layer moved from httpx to httpx2, a maintained API-compatible fork; the SDK now requires Python 3.10+ and dropped legacy Text Completions and sampling parameters.
- The computer use tool is now generally available with no beta header required, adding batch actions, default zoom, and per-member configuration.
- A new browser use tool lets applications drive a browser viewport via its accessibility tree, with element references, form input, tab management, and file upload.
- The Files API, Agent Skills/Skills API, and Claude Enterprise user-management endpoints are all now generally available and no longer require their respective beta headers.
- Web search and web fetch tools for Managed Agents can now be restricted to allowed or blocked domains, with additional content and location controls.
- Managed Agents sessions running in self-hosted sandboxes can now attach memory stores that sync automatically.
- The Claude Console's session viewer was redesigned with a timeline, grouped transcript, and an inspector panel; Workbench was renamed Playground.
- The Compliance API can now return transcripts of Cowork and Claude Code sessions running on user machines, and a new response header identifies the workspace behind each API request.
- Claude Sonnet 5's introductory pricing became the permanent standard price, with the scheduled increase cancelled.
- Managed Agents sessions gained budget caps, an "advisor" model role, configurable inference region, and skill loading from GitHub repositories.
- Claude Opus 5 launched with a 1M token context window, 128k max output, thinking on by default, and a stricter effort/thinking interaction than Opus 4.8.
- Fast mode was removed for Claude Opus 4.7, with requests now erroring instead of falling back to standard speed.
- Session event streams for Managed Agents now support delta previews and backward pagination, and sessions can be created with per-session configuration overrides.

## SDK Changes

- Python SDK v1.0 requires building custom HTTP client/timeout/transport objects from httpx2 instead of httpx, and calling `httpx2.alias_httpx()` for tracing/mocking compatibility.
- `AnthropicBedrock` now raises an error when no AWS region is configured instead of silently defaulting to us-east-1.
- Async client `.with_raw_response` results now require `await response.parse()`.
- The memory store beta header changed from `managed-agents-2026-04-01` to `agent-memory-2026-07-22`, altering pagination and filtering behavior; SDKs across Python, TypeScript, Go, Java, Ruby, PHP, C#, and CLI now send the new header by default.

## Bug Fixes

- Fixed unsupported `mid_conv_system` content block being sent in requests.
- Fixed platform header computation spawning an unnecessary subprocess.
- Fixed missing exports for custom status errors and `ServiceUnavailableError`/`DeadlineExceededError` from the package root.
- Fixed tool-result sends not retrying for the full lease TTL in the session runner.
- Fixed synchronous session tools blocking the event loop instead of running in a worker thread.
- Fixed spurious warnings about `output_format=` on parse/stream/tool_runner helpers.
